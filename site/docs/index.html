Beepack Scan documentation

Open-source safety scanner for Claude Code skills and any markdown that ships install commands. Deterministic rules, no LLM, free.

What it does

Given a SKILL.md (and optional supporting scripts), the scanner extracts every install command, URL, and import, then validates each reference against real data sources. It returns a single RED / YELLOW / GREEN verdict plus a list of findings pinned to the exact line that triggered them.

Why it exists

In December 2025, Aikido disclosed that AI-generated agent skills routinely reference npm or PyPI packages that do not exist. An attacker who registers the hallucinated name can ship malware to every machine that installs the skill. No existing tool checks skills specifically, so we built one.

How to use it

  • Web UI: paste a URL, drop a file, or paste markdown at beepack.ai/scan. Zero setup.
  • CLI: beepack scan <url-or-path> with exit codes for pre-install hooks.
  • HTTP API: POST /api/v1/scan for integrations and batch runs.
  • MCP tool and GitHub Action are on the roadmap for V2.

What it does not do

  • No LLM-based code review. We validate against registries and blocklists, period. This keeps results reproducible and free to run.
  • No arbitrary-code scanning. Skill-specific scope. Code vulnerability scanning is covered by Snyk, Socket.dev, and friends.
  • No approval registry. The output is a verdict, not a seal. You decide whether to install.
  • Not a replacement for Anthropic Skills. We aim to make Skills safer, not compete.
