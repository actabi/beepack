Scan via web UI

The fastest way to scan a skill. No account, no setup, under 10 seconds.

Go to beepack.ai/scan. You have three input modes.

Mode 1: paste a URL

Accepts any of these shapes:

  • GitHub repo: https://github.com/owner/repo. The scanner fetches SKILL.md from the default branch and any .sh, .py, .js, or .ts files in the same folder.
  • GitHub folder: https://github.com/owner/repo/tree/branch/path. Same behavior, scoped to the folder.
  • GitHub blob: https://github.com/owner/repo/blob/branch/path/SKILL.md. Scans that file plus sibling scripts.
  • Raw GitHub: https://raw.githubusercontent.com/owner/repo/branch/path/SKILL.md. Scans only the markdown.
  • Gist: https://gist.github.com/user/id. Picks the first markdown file in the gist.

Mode 2: drop files

Drop a SKILL.md onto the file zone, or click to select. You can include multiple files; the scanner treats the first .md as the skill and the rest as referenced scripts.

Size caps: 2 MB per file, 20 files max.

Mode 3: paste markdown

Paste raw SKILL.md content directly. Useful for quick checks of markdown you're drafting or reading inline in a chat.

Reading the result

The verdict card appears within 10 seconds for most skills. Three colors:

  • RED: at least one blocking issue (hallucinated package, strong typosquat, URLhaus match). Do not install as-is.
  • YELLOW: no blockers but warnings worth a human look (young domain, pastebin URL, weaker typosquat).
  • GREEN: every reference resolved to a real, known-good target.

Each finding shows severity, type, a short message, and the exact source:line location. See Verdicts and findings for the full rule list.

Sharing a scan

Every scan gets a permanent URL: beepack.ai/scan?id=<scan-id>. Copy it from the "Share this scan" field under the result card. Scan results are public and immutable.

Privacy

We store the scan result (verdict, findings, stats, source URL or filename) in SQLite on our server. We do not store uploaded file contents beyond the parse step. Your IP is hashed with a salted SHA-256 for duplicate-visitor counting; the raw IP is never persisted.

If you need a fully offline flow, see Self-hosting.
