Scan HTTP API

Three endpoints. No auth required on the public instance. JSON in, JSON out.

Base URL: https://beepack.ai/api/v1

POST /api/v1/scan

Run a scan. Accepts three input modes in the body. Use one.

Mode A: URL

POST /api/v1/scan
Content-Type: application/json

{ "url": "https://github.com/owner/repo" }

The server fetches the skill from the given URL (same resolution rules as the web UI: GitHub repo, blob, tree, gist, raw).

Mode B: pasted markdown

POST /api/v1/scan
Content-Type: application/json

{
  "markdown": "# My skill\n\n```bash\nnpx @my/tool\n```",
  "source": "inline-demo",
  "scripts": [
    { "name": "install.sh", "content": "pip install requests" }
  ]
}

scripts is optional. Each entry must have name and content (strings).

Mode C: multipart file upload

POST /api/v1/scan
Content-Type: multipart/form-data

files: SKILL.md
files: install.sh

The first .md file is treated as the skill, others as supporting scripts. Size caps: 2 MB per file, 20 files.

Response

{
  "scanId": "f04b19b7-fc7e-4c87-9abb-36640211c6bd",
  "scannedAt": "2026-04-21T13:50:27.783Z",
  "source": "https://github.com/owner/repo",
  "verdict": "red",
  "summary": "1 critical: npm package \"@fake/xyz\" does not exist on the registry",
  "findings": [
    {
      "severity": "block",
      "type": "package_does_not_exist",
      "ecosystem": "npm",
      "package": "@fake/xyz",
      "message": "npm package \"@fake/xyz\" does not exist on the registry",
      "locations": [{ "source": "SKILL.md", "line": 5, "reason": "npx" }]
    }
  ],
  "stats": {
    "shellCommands": 3, "urls": 2, "npmPackages": 4,
    "pipPackages": 0, "imports": 1
  }
}

verdict is red, yellow, or green. See Verdicts and findings for the full rule set and the list of possible type values.

Errors

400 { "error": { "code": "INVALID_INPUT", "message": "..." } }
400 { "error": { "code": "SCAN_FAILED",  "message": "..." } }
429 { "error": { "code": "SCAN_RATE_LIMIT", "message": "Too many scans..." } }

Rate limits

30 scans per minute per IP on the public instance. Contact us if you need headroom.

GET /api/v1/scan/:id

Retrieve a previously-run scan by ID. Returns the same shape as POST /api/v1/scan.

curl https://beepack.ai/api/v1/scan/f04b19b7-fc7e-4c87-9abb-36640211c6bd

Returns 404 if the ID is unknown.

GET /api/v1/scan-stats

Aggregate stats over a time window. Useful for embedding counters on your own dashboard.

GET /api/v1/scan-stats?hours=24

{
  "total": 128,
  "uniqueIps": 42,
  "byVerdict": { "green": 70, "yellow": 40, "red": 18 },
  "topSources": [
    { "source": "https://github.com/x/y", "n": 7 }
  ]
}

Query parameter hours defaults to 24. Sources equal to "paste" are excluded from topSources.

Example: GitHub Action

Fail the build on RED or YELLOW verdicts for any PR touching a skill file.

name: scan-skills
on: pull_request
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: scan
        run: |
          for f in $(git diff --name-only origin/main | grep -E 'SKILL\.md$'); do
            curl -sS -X POST https://beepack.ai/api/v1/scan \
              -H 'Content-Type: application/json' \
              -d "$(jq -Rn --arg md "$(cat $f)" '{markdown:$md,source:"'$f'"}')" \
            | tee scan-$f.json
            verdict=$(jq -r .verdict scan-$f.json)
            [ "$verdict" = "green" ] || exit 1
          done

A managed GitHub Action is on the V2 roadmap; this inline version works today.
