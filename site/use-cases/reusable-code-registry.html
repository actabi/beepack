A registry, but deliberately narrow

npm has 3 million packages. We have 5. That's the point.

🧬

Source code, not a dependency

When you pull from Beepack, the actual source files land in your repo. Modify them, adapt them, delete our README - it's yours. No runtime dependency.

🎯

Narrow on purpose

We only add a package when a frontier LLM reliably hallucinates this API. If Claude zero-shots it well, we don't duplicate that work.

MCP-native discovery

Your AI can query the registry directly. Because we're narrow, the MCP results only fire when they're actually useful - no context pollution.

HIVE.yaml - the manifest

Every package declares what it does via a HIVE.yaml. AI agents and the registry use it for discovery and compatibility.

  • Declare capabilities so AI agents know what your package does
  • Specify required environment variables
  • Version your packages for stable references
  • SKILL.md-compatible export on the roadmap (Anthropic Agent Skills standard)
# HIVE.yaml - package manifest
name: siret-utils
version: 1.0.0
description: Validate and format French SIRET/SIREN (Luhn)

keywords:
  - siret
  - siren
  - french-regulatory
  - luhn

capabilities:
  - validate_siret
  - format_siret
  - format_siren

requires:
  env: []   # zero deps, zero env

compatible:
  - cursor
  - claude
  - copilot
  - openclaw
