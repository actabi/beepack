# prisma

> **Prisma ORM** — [prisma/prisma](https://github.com/prisma/prisma) | 45,723 stars | Apache-2.0 license

Next-generation ORM for Node.js and TypeScript. Declarative schema, auto migrations, and typesafe client for PostgreSQL, MySQL, SQLite, MongoDB.

This beepack package provides integration helpers and references the official [prisma/prisma](https://github.com/prisma/prisma) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/prisma/prisma for the latest install instructions
npm install prisma
```

For beepack usage:

```bash
beepack install prisma
```

## Environment Variables

```bash
DATABASE_URL=your-value-here
```

- **Schema Management**
- **Auto Migrations**
