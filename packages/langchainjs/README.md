# langchainjs

> **LangChain.js** — [langchain-ai/langchainjs](https://github.com/langchain-ai/langchainjs) | 17,450 stars | MIT license

The agent engineering platform for JavaScript/TypeScript. Build complex LLM apps with chains, agents, RAG, and vector stores.

This beepack package provides integration helpers and references the official [langchain-ai/langchainjs](https://github.com/langchain-ai/langchainjs) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/langchain-ai/langchainjs for the latest install instructions
npm install langchainjs
```

For beepack usage:

```bash
beepack install langchainjs
```

## Environment Variables

```bash
OPENAI_API_KEY=your-value-here
```
