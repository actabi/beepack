# zod

> **Zod** — [colinhacks/zod](https://github.com/colinhacks/zod) | 42,339 stars | MIT license

TypeScript-first schema validation with static type inference. The standard validation library used everywhere (tRPC, React Hook Form, etc.).

This beepack package provides integration helpers and references the official [colinhacks/zod](https://github.com/colinhacks/zod) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/colinhacks/zod for the latest install instructions
npm install zod
```

For beepack usage:

```bash
beepack install zod
```
