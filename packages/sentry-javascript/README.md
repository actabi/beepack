# sentry-javascript

> **Sentry JavaScript SDK** — [getsentry/sentry-javascript](https://github.com/getsentry/sentry-javascript) | 8,623 stars | MIT license

Official Sentry SDKs for JavaScript. Error tracking and performance monitoring for Next.js, React, and Node.js.

This beepack package provides integration helpers and references the official [getsentry/sentry-javascript](https://github.com/getsentry/sentry-javascript) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/getsentry/sentry-javascript for the latest install instructions
npm install sentry-javascript
```

For beepack usage:

```bash
beepack install sentry-javascript
```

## Environment Variables

```bash
SENTRY_DSN=your-value-here
```

## Capabilities

- **Error Capture**
- **Performance Tracing**
- **Breadcrumbs**
- **User Feedback**
- **Release Tracking**
- **Source Maps**

## Usage

```js
import { getSetupGuide } from "./index.js";
console.log(getSetupGuide());
```

For full API documentation and examples, visit [getsentry/sentry-javascript](https://github.com/getsentry/sentry-javascript).
