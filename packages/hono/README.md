# hono

> **Hono** — [honojs/hono](https://github.com/honojs/hono) | 29,824 stars | MIT license

Web framework built on Web Standards. Ultrafast, works on Cloudflare Workers, Deno, Bun, and Node.js.

This beepack package provides integration helpers and references the official [honojs/hono](https://github.com/honojs/hono) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/honojs/hono for the latest install instructions
npm install hono
```

For beepack usage:

```bash
beepack install hono
```

## Capabilities

- **Http Routing**
- **Middleware**
- **Request Parsing**
- **Response Helpers**
- **Cors**
- **Jwt Auth**

```js
import { getSetupGuide } from "./index.js";
console.log(getSetupGuide());
```
