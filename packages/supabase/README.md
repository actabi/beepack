# supabase

> **Supabase** — [supabase/supabase](https://github.com/supabase/supabase) | 100,518 stars | Apache-2.0 license

The Postgres development platform. Complete backend-as-a-service with auth, database, storage, realtime, and edge functions.

This beepack package provides integration helpers and references the official [supabase/supabase](https://github.com/supabase/supabase) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/supabase/supabase for the latest install instructions
npm install supabase
```

For beepack usage:

```bash
beepack install supabase
```

## Environment Variables

```bash
SUPABASE_URL=your-value-here
SUPABASE_ANON_KEY=your-value-here
```

## Capabilities

- **Database Queries**
- **Auth Management**
- **File Storage**
- **Realtime Subscriptions**
- **Edge Functions**
- **Rpc Calls**
