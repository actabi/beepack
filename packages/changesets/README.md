# changesets

> **Changesets** — [changesets/changesets](https://github.com/changesets/changesets) | 11,652 stars | MIT license

Manage versioning and changelogs with a focus on monorepos. Automate releases and npm publishing.

This beepack package provides integration helpers and references the official [changesets/changesets](https://github.com/changesets/changesets) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/changesets/changesets for the latest install instructions
npm install changesets
```

For beepack usage:

```bash
beepack install changesets
```
