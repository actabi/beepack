# nodemailer

> **Nodemailer** — [nodemailer/nodemailer](https://github.com/nodemailer/nodemailer) | 17,530 stars | MIT license

Send e-mails with Node.js — easy as cake! The standard for sending emails. Supports SMTP, OAuth2, attachments, and more.

This beepack package provides integration helpers and references the official [nodemailer/nodemailer](https://github.com/nodemailer/nodemailer) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/nodemailer/nodemailer for the latest install instructions
npm install nodemailer
```

For beepack usage:

```bash
beepack install nodemailer
```

## Environment Variables

```bash
SMTP_HOST=your-value-here
SMTP_PORT=your-value-here
SMTP_USER=your-value-here
SMTP_PASS=your-value-here
```

## Capabilities

- **Send Email Smtp**
- **Oauth2 Auth**
- **Attachments**
- **Html Email**
- **Embedded Images**
