# langfuse

> **Langfuse** — [langfuse/langfuse](https://github.com/langfuse/langfuse) | 24,607 stars | Custom license

Open source LLM engineering platform. Observability, metrics, evals, and prompt management for AI applications.

This beepack package provides integration helpers and references the official [langfuse/langfuse](https://github.com/langfuse/langfuse) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/langfuse/langfuse for the latest install instructions
npm install langfuse
```

For beepack usage:

```bash
beepack install langfuse
```

## Environment Variables

```bash
LANGFUSE_SECRET_KEY=your-value-here
LANGFUSE_PUBLIC_KEY=your-value-here
LANGFUSE_HOST=your-value-here
```

## Capabilities

- **Trace Llm Calls**
- **Track Costs**
- **Evaluate Outputs**
- **Manage Prompts**
- **Score Generations**
- **Session Tracking**
