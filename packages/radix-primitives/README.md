# radix-primitives

> **Radix UI Primitives** — [radix-ui/primitives](https://github.com/radix-ui/primitives) | 18,735 stars | MIT license

Open-source headless UI component library for building accessible design systems. The foundation of shadcn/ui.

This beepack package provides integration helpers and references the official [radix-ui/primitives](https://github.com/radix-ui/primitives) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/radix-ui/primitives for the latest install instructions
npm install radix-primitives
```

For beepack usage:

```bash
beepack install radix-primitives
```

## Capabilities

- **Dialog**
- **Dropdown Menu**
- **Popover**
- **Tooltip**
- **Accordion**
- **Tabs**
- **Select**
- **Slider**

## Usage

```js
import { getSetupGuide } from "./index.js";
console.log(getSetupGuide());
```

For full API documentation and examples, visit [radix-ui/primitives](https://github.com/radix-ui/primitives).
