# vercel-ai

> **Vercel AI SDK** — [vercel/ai](https://github.com/vercel/ai) | 23,339 stars | Custom license

The AI Toolkit for TypeScript. Streaming, tool calling, agents. Supports OpenAI, Anthropic, Google, and more LLM providers.

This beepack package provides integration helpers and references the official [vercel/ai](https://github.com/vercel/ai) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/vercel/ai for the latest install instructions
npm install vercel-ai
```

For beepack usage:

```bash
beepack install vercel-ai
```

## Environment Variables

```bash
OPENAI_API_KEY=your-value-here
```

- **Llm Streaming**
- **Tool Calling**

import { getSetupGuide } from "./index.js";
