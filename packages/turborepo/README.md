# turborepo

> **Turborepo** — [vercel/turborepo](https://github.com/vercel/turborepo) | 30,149 stars | MIT license

Build system optimized for JavaScript and TypeScript monorepos. Intelligent caching, parallelization, and incremental builds.

This beepack package provides integration helpers and references the official [vercel/turborepo](https://github.com/vercel/turborepo) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/vercel/turborepo for the latest install instructions
npm install turborepo
```

For beepack usage:

```bash
beepack install turborepo
```

## Capabilities

- **Task Caching**
- **Parallel Execution**
- **Incremental Builds**
- **Remote Caching**
- **Pipeline Definition**
- **Workspace Management**
