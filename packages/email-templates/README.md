# email-templates

> **Email Templates** — [forwardemail/email-templates](https://github.com/forwardemail/email-templates) | 3,728 stars | MIT license

Create, preview, and send custom email templates for Node.js. Supports multiple template engines and preview in browser.

This beepack package provides integration helpers and references the official [forwardemail/email-templates](https://github.com/forwardemail/email-templates) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/forwardemail/email-templates for the latest install instructions
npm install email-templates
```

For beepack usage:

```bash
beepack install email-templates
```

## Environment Variables

```bash
SMTP_HOST=your-value-here
SMTP_PORT=your-value-here
SMTP_USER=your-value-here
SMTP_PASS=your-value-here
```

- **Preview Emails**
