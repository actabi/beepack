# uploadthing

> **UploadThing** — [pingdotgg/uploadthing](https://github.com/pingdotgg/uploadthing) | 5,086 stars | MIT license

File uploads for modern web devs. Typesafe, simple file upload solution for Next.js and React applications.

This beepack package provides integration helpers and references the official [pingdotgg/uploadthing](https://github.com/pingdotgg/uploadthing) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/pingdotgg/uploadthing for the latest install instructions
npm install uploadthing
```

For beepack usage:

```bash
beepack install uploadthing
```

## Environment Variables

```bash
UPLOADTHING_SECRET=your-value-here
UPLOADTHING_APP_ID=your-value-here
```

## Capabilities

- **File Upload**
- **Image Upload**
- **File Validation**
- **Presigned Urls**
- **Upload Callbacks**
