# trpc

> **tRPC** — [trpc/trpc](https://github.com/trpc/trpc) | 39,946 stars | MIT license

End-to-end typesafe APIs made easy. The client knows the server types. Perfect for full-stack TypeScript monorepos.

This beepack package provides integration helpers and references the official [trpc/trpc](https://github.com/trpc/trpc) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/trpc/trpc for the latest install instructions
npm install trpc
```

For beepack usage:

```bash
beepack install trpc
```

## Capabilities

- **Typesafe Api**
- **Query Mutation**
- **Subscriptions**
- **Middleware**
- **Input Validation**
- **Error Handling**

## Usage

```js
import { getSetupGuide } from "./index.js";
console.log(getSetupGuide());
```

For full API documentation and examples, visit [trpc/trpc](https://github.com/trpc/trpc).
