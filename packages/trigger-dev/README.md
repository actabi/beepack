# trigger-dev

> **Trigger.dev** — [triggerdotdev/trigger.dev](https://github.com/triggerdotdev/trigger.dev) | 14,444 stars | Apache-2.0 license

Build and deploy fully-managed AI agents and background workflows. Modern alternative to traditional job queues.

This beepack package provides integration helpers and references the official [triggerdotdev/trigger.dev](https://github.com/triggerdotdev/trigger.dev) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/triggerdotdev/trigger.dev for the latest install instructions
npm install trigger-dev
```

For beepack usage:

```bash
beepack install trigger-dev
```

## Environment Variables

```bash
TRIGGER_API_KEY=your-value-here
TRIGGER_API_URL=your-value-here
```

## Capabilities

- **Background Jobs**
- **Scheduled Tasks**
- **Webhook Triggers**
- **Workflow Orchestration**
- **Retry Logic**
