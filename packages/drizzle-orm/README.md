# drizzle-orm

> **Drizzle ORM** — [drizzle-team/drizzle-orm](https://github.com/drizzle-team/drizzle-orm) | 33,754 stars | Apache-2.0 license

Lightweight TypeScript ORM with SQL-like syntax. Zero dependencies, performant, and close to raw SQL.

This beepack package provides integration helpers and references the official [drizzle-team/drizzle-orm](https://github.com/drizzle-team/drizzle-orm) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/drizzle-team/drizzle-orm for the latest install instructions
npm install drizzle-orm
```

For beepack usage:

```bash
beepack install drizzle-orm
```

## Environment Variables

```bash
DATABASE_URL=your-value-here
```

## Capabilities

- **Sql Like Queries**
- **Schema Definition**
- **Migrations**
- **Relations**
- **Transactions**
- **Prepared Statements**
