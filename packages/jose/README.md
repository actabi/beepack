# jose

> **jose — JWT/JWK/JWS/JWE** — [panva/jose](https://github.com/panva/jose) | 7,487 stars | MIT license

JWA, JWS, JWE, JWT, JWK, JWKS for Node.js, Browser, Cloudflare Workers, Deno, and Bun. The reference JWT library for JavaScript runtimes.

This beepack package provides integration helpers and references the official [panva/jose](https://github.com/panva/jose) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/panva/jose for the latest install instructions
npm install jose
```

For beepack usage:

```bash
beepack install jose
```

## Capabilities

- **Jwt Sign**
- **Jwt Verify**
- **Jws Sign**
- **Jws Verify**
- **Jwe Encrypt**
- **Jwe Decrypt**
- **Jwk Generate**
- **Jwks Fetch**
