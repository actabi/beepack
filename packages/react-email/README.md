# react-email

> **React Email** — [resend/react-email](https://github.com/resend/react-email) | 18,364 stars | MIT license

Build and send emails using React components. Beautiful transactional emails with JSX instead of HTML tables.

This beepack package provides integration helpers and references the official [resend/react-email](https://github.com/resend/react-email) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/resend/react-email for the latest install instructions
npm install react-email
```

For beepack usage:

```bash
beepack install react-email
```

## Capabilities

- **Render Email Html**
- **React Components**
- **Email Preview**
- **Responsive Templates**

## Usage

```js
import { getSetupGuide } from "./index.js";
console.log(getSetupGuide());
```

For full API documentation and examples, visit [resend/react-email](https://github.com/resend/react-email).
