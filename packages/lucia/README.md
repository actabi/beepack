# lucia

> **Lucia Auth** — [lucia-auth/lucia](https://github.com/lucia-auth/lucia) | 10,454 stars | 0BSD license

Authentication, simple and clean. Minimalist session-based auth library for full control over your authentication flow.

This beepack package provides integration helpers and references the official [lucia-auth/lucia](https://github.com/lucia-auth/lucia) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/lucia-auth/lucia for the latest install instructions
npm install lucia
```

For beepack usage:

```bash
beepack install lucia
```

## Capabilities

- **Session Management**
- **User Creation**
- **Password Hashing**
- **Session Validation**

## Usage

```js
import { getSetupGuide } from "./index.js";
console.log(getSetupGuide());
```

For full API documentation and examples, visit [lucia-auth/lucia](https://github.com/lucia-auth/lucia).
