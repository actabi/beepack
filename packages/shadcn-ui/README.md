# shadcn-ui

> **shadcn/ui** — [shadcn-ui/ui](https://github.com/shadcn-ui/ui) | 111,856 stars | MIT license

Beautifully-designed, accessible UI components. Copy-paste into your project, not a dependency. 100% customizable with Tailwind CSS.

This beepack package provides integration helpers and references the official [shadcn-ui/ui](https://github.com/shadcn-ui/ui) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/shadcn-ui/ui for the latest install instructions
npm install shadcn-ui
```

For beepack usage:

```bash
beepack install shadcn-ui
```

## Capabilities

- **Ui Components**
- **Form Elements**
- **Data Display**
- **Navigation**
- **Feedback**
- **Theming**

## Usage

```js
import { getSetupGuide } from "./index.js";
console.log(getSetupGuide());
```

For full API documentation and examples, visit [shadcn-ui/ui](https://github.com/shadcn-ui/ui).
