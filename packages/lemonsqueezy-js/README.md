# lemonsqueezy-js

> **Lemon Squeezy JS SDK** — [lmsqueezy/lemonsqueezy.js](https://github.com/lmsqueezy/lemonsqueezy.js) | 524 stars | MIT license

Official JavaScript SDK for Lemon Squeezy. Simple payment integration for SaaS and digital products.

This beepack package provides integration helpers and references the official [lmsqueezy/lemonsqueezy.js](https://github.com/lmsqueezy/lemonsqueezy.js) repository.

## Installation

For production use, install the official package:

```bash
# See https://github.com/lmsqueezy/lemonsqueezy.js for the latest install instructions
npm install lemonsqueezy-js
```

For beepack usage:

```bash
beepack install lemonsqueezy-js
```

## Environment Variables

```bash
LEMONSQUEEZY_API_KEY=your-value-here
LEMONSQUEEZY_STORE_ID=your-value-here
```

## Capabilities

- **Create Checkout**
- **Manage Subscriptions**
- **Handle Webhooks**
- **List Products**
- **Manage Licenses**

## Usage

```js
import { getSetupGuide } from "./index.js";
console.log(getSetupGuide());
```

For full API documentation and examples, visit [lmsqueezy/lemonsqueezy.js](https://github.com/lmsqueezy/lemonsqueezy.js).
